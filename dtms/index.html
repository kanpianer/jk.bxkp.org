🌐 在线安全管理模式 (仅作者使用)

若您需要在公网或出差时随时随地在线修改导航卡片，可启用 GitHub REST API 客户端直连模式：

  1. 在 GitHub Settings -> Developer settings -> Personal access tokens (fine-grained) 中生成一个仅针对 kanpianer/jk.bxkp.org 仓库具备 Contents 写入权限的专用 Token。
  2. 在下方输入您的 Token（仅保存在您的本地浏览器 localStorage 中，绝不上传到任何服务器）。
  3. 保存时，前端将直接调用 GitHub API 向仓库提交 Commit，只有作者账号有权成功写入，任何其他人均无权篡改！
  4. 进阶安全建议：在 Cloudflare Zero Trust 中为 /dtms/* 配置 Access 策略，要求输入您的作者邮箱接收 PIN 码后方可打开。
